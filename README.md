## 🚀 Featured Projects

### 💹 [FinLens](https://github.com/H3D1/finlens)

**Version 0.4 · Personal Fintech Application**

`Java` `Spring Boot` `Python` `FastAPI` `React` `TypeScript` `PostgreSQL` `Docker`

A microservices application that combines financial account data, spending insights, and transaction anomaly detection in one dashboard.

- **Aggregation service:** Spring Boot API for authentication and account-data retrieval.
- **Insights service:** FastAPI service for rule-based spending observations and balance projections.
- **Fraud service:** FastAPI service that flags unusual bursts of outgoing transactions using a rolling time-window rule.
- **Frontend:** React and TypeScript dashboard presenting accounts, transactions, insights, and fraud flags.
- **Service communication:** Analytical services retrieve account data through the aggregation API over HTTP.
- **Testing:** Automated tests for backend logic and service functionality.

**Engineering concepts explored:** microservices, REST APIs, JWT authentication, service-to-service communication, separation of concerns, and the trade-offs of rule-based anomaly detection.

FinLens uses demonstration financial data and does not connect to real banks or process payments.
